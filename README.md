# Muhammad Aashir Mehboob — Performance Marketing Portfolio

A responsive, single-page portfolio website built with plain HTML, CSS and JavaScript.

## Deploy on Netlify
1. Extract `aashir-performance-portfolio.zip`.
2. Open Netlify and choose **Add new site → Deploy manually** (or drag-and-drop deploy).
3. Drag the extracted `aashir-performance-portfolio` folder into the deploy area.
4. Netlify will publish `index.html` from the root. No build command or publish directory is required.

## Files
- `index.html` — all page sections and content
- `styles.css` — responsive styling and animations
- `script.js` — mobile navigation and scroll progress
- `assets/aashir.jpg` — supplied profile photo
- `assets/zayora-meta-report.png` — Meta Ads report image rendered from the supplied PDF, page 1
- `assets/client-brand-board.png` — brand logo sheet rendered from the supplied PDF, page 2
